## 职业选择与构筑


职业推荐优先度：法师>战士>萨满>弓箭手>刺客

这里仅推荐新手用法师和战士作为lr起步选择。

另外，还是非常建议新手120再开始考虑LR的事，此时能获得更加强力的配装和技能树。

TP蹭怪，开出裂缝(dimention tear)

在裂缝持续期间，用shift+治疗可以把裂缝背到身上(这个叫riftbound)，此时你的扭曲(distortion)将会暂停衰减。

### 战士

战士在战斗方面有着非常舒适的续航以及抗伤能力，目前三条线均在LR有说法，续航都还算可以。但是速度可能没有法师快，属于是比较舒服但是不够爽。

+ Charging Flame - 40int 40def：-16 charge cost，**用于跑图**
+ Catamaran - 40int 40agi：**用于奶自己**

### 萨满

萨满的战斗输出非常强劲，自身也有非常恐怖的续航，但问题是位移手段太烂了，需要绑定某些装备才能获得较好的位移体验，否则很多时间都是浪费在跑图上。当然，萨满LR的难度还是太大了，因此不怎么推荐给新手
  
### 弓箭手

弓箭手在更新后可以用Sharpshooter稍微跑一下，但要注意抗压能力极差，并且跑图体验不是很好。

### 刺客

可以用acrobat跑，但仍然缺少一定的抗压能力。

## 运营要点


这里把整局游戏分为若干目标，你可以对照着来完成：

<span style="font-size: 20px; border-bottom: 3px solid #FFCC00; padding-bottom: 4px; font-weight: bold;">扩充信标选数</span>

橙信标在开局的刷率会很高，优先吃橙信标来获取信标选数，吃到5选即可

需要注意记一下过期时间，在过期前记得及时续上橙信标

信标选数的作用是让你更好获取你想获得的信标，非常重要。



如果有<font color='FFAA00'> **High Spirits** </font>，也可以考虑吃两个vib青+vib橙来获得25轮的信标选数，比较划算。

等到10轮以后，就会有机会出现彩虹信标，但是由于出率问题，下文讨论都会基于无彩虹环境。

这里笔者其实不推荐强追彩虹，因为刚开始的出率实在太低了，很容易把所有的信标reroll次数给浪费掉。

建议保持信标选数，直到20-30轮，彩虹一般会自然出现，到时候直接吃即可

<span style="font-size: 20px; border-bottom: 3px solid #FFCC00; padding-bottom: 4px; font-weight: bold;">扩充轮次数</span>

12轮肯定是不够跑的。

除了<font color='FF5555'> **Knife Edge** </font>以外，建议时刻保持轮次数余量在10以上。

你需要通过吃红信标来扩充轮次数

如果信标给的恰当，也可以考虑在吃红之前叠个青。

对于白信标，比较建议在给25轮或者30轮的时候吃，这样划算，刷出野生vib青的时候就可以考虑吃白了，或者也可以靠连续青来强吃。







<span style="font-size: 20px; border-bottom: 3px solid #FFCC00; padding-bottom: 4px; font-weight: bold;">保持属性健康</span>

如果条件允许，在前期可以吃2-3个Boon，如果能吃到Killstreak且属性正确的话，很长时间内都不用再吃了。

你的BD决定了你能拿多少Boon，如果觉得打的吃力了，务必一定要多拿Boon。

如果拿到了<font color='FFAA00'> **High Spirits** </font>或者彩虹，也可以考虑吃两个400% potency的Boon来快速提高数值。

如果有<font color='AA00AA'> **Equilibrium** </font>，记得随时补诅咒和Boon。

另外，为了吃到Madman的Boon类型，你需要提前吃8个curse来保证一定能拿满。



<span style="font-size: 20px; border-bottom: 3px solid #FFCC00; padding-bottom: 4px; font-weight: bold;">关于任务</span>

在第四轮完成时，你可以从3个任务中选择一个并接受，完成后即可获得该任务的效果。

在当前没有接受任务时，灰色信标会自然刷新。

这里建议读者在确保信标选数充足和轮次数充足的情况下，快速做完任务。

原因很简单，任务只有完成后，才能获得收益；越晚完成任务，你能获得的收益就越少。

在接取任务前，务必提前吃一个甚至两个青，来让你获得4-5选的灰色信标，否则你基本很难接到理想的任务。

请注意，安排好完成任务的时机，如果是开箱或者获得时间的条件，尽可能让你吃到青后再让灰有机会生成。灰色信标出现的越多而你拿，那么灰色信标的刷率就会越来越低直至消失。你最多大概可以跳过10次灰色信标不拿。

这里比较建议读者在30轮前就完成所有任务，最理想的情况20轮就可以完成了。

开箱的条件用前文说的，F3+B快速找野箱。

获取时间的条件如果在白信标轮次内很好做，但是如果在红信标轮次会非常拖沓，强烈建议青绿循环来快速完成。

诅咒和祝福的条件就没啥好说的了，唯一要说的是诅咒看到VIB紫最好直接去拿，省一轮轮次数。

至于Pulls的条件，除了紫信标以外，注意你已经完成的任务是否有可以直接给予Pulls的。

<span style="font-size: 20px; border-bottom: 3px solid #FFCC00; padding-bottom: 4px; font-weight: bold;">关于试炼</span>

试炼可以被视作是一个更强大的任务。

接取试炼需要从绯红信标中接取。

在第19轮的时候，你就可以提前吃青信标了，并且提前预留信标刷新次数，以确保你能在20轮时吃到被青强化的绯红信标；被青信标强化的绯红十分重要，你必须要至少3选及以上的绯红信标才能保证尽可能不鬼抽。

试炼的选择在下文会有提到，这里只是简单概括。

某些试炼会迫使你改变运营重点，例如Lights Out会大幅改变你的游戏思路。

而某些试炼会在一定轮次内给你施加负面效果，顺利打完之后即可完成。

总的来说，试炼是能给予大量RR/SAC/Pulls的方式。

另外，绯红信标的刷率非常低，在信标选数较少时可能很难刷新。同时，跳过约5-6次后，它将不再刷新，请注意运营。

## 增益选择


`Max Mana`看个人，比较不推荐选，主要是这玩意还有上限，非常蛋疼，但是能提高首刀和位移舒适度是真的。

`Walk Speed`也是提升舒适度的，一般用位移走路的不怎么选。~~萨满可以选~~

属性点看个人，如果某一个属性点非常缺甚至几乎没有，那还是很推荐拿的，最好一次拿满。

`Loot Bouns`，`Loot Quality`在你一点都没有的情况下可以拿(但是不如先拿伤害和生存)，前者拿满80%，后者拿满40%即可，不需要拿太多，衰减严重。

`Health Regen`，`Weaken Enemy`，`Health`都是生存向的增益，如果你觉得生存非常吃力，最好多拿几个。

要注意`Weaken Enemy`几乎必拿，上限50%，建议一次拿满。

`Mana Regen`，`Damage`，`Element Damage`，`Critical Damage`看到就拿，无脑提升伤害。

当然，以上都只是最基础的东西，你真正需要看的是**数值**

是的，不同增益类型的数值是不一样的。

首先，<font color = FF5555>**Killstreak**</font>如果给的属性恰当，看到就拿，这个能提供最高的属性加成，但是中后期不会给。

其次，<font color = FF55FF>**Bad Omen**</font>的数值也比较不错，可以拿。<font color = FF55FF>**Madman**</font>如果你的诅咒够，也是必拿。






## 任务选择



这玩意其实才是大头，~~让我头大的玩意~~

目前的版本中，任务直接决定了收益，好的任务能让你收益暴增，而烂任务会让你的游戏体验暴跌。

这里将任务分为三个种类：运营类、奖励类、战斗类。

运营类能降低你的运营压力，甚至改变游戏玩法。

奖励类能直接提高最终奖励，包括但不限于增加飞箱/增加重掷次数等。

另外，奖励类细分为飞箱和结算两种流派。

战斗类能降低你的战斗压力，通常跑长途需要这一类中的至少一个任务。

## 关于效率

你也许在"任务选择"中，看到了"局内pulls"和"局外pulls"这两个说法

下面让我来解释一下这两者的定义：

局内pulls，指该任务提供的pulls依赖所完成的信标，且有极大可能非常依赖彩虹信标。只有你完成了对应的信标，才能获取任务所指示的pulls

局外pulls，指该任务提供的pulls基本不依赖或很少依赖所完成的信标，例如knife edge提供的pulls大部分情况下只需要你每六轮续一次红，其他时间做其他信标就可以了。


在分清这两者之后，你需要根据你的任务组来选择信标抓位。然后这里提供一个"轮均pulls"的概念。该指标越高，这把lr效率越高。一般来说，以最终结算为准，如果你觉得这把的轮均pulls不算很高，强烈建议及时退出止损时间。

当然，你也可以用下面的轮均pulls来判断任务效率，但是这里的数值都是暖机后的数据，特别是局内pulls刚需彩虹。

一般来说，局内pulls如果出现冲突的情况，则建议避免拿取冲突的任务；而局外pulls一般很少会有冲突的情况，但可能会有一定的负面效果。

局内pulls和局外pulls的任务相结合，可能会有意想不到的好效果。

但你仍然可以看到其所指引的挑战地点。

另外，如果存在多个遮蔽信标，并且有些有Vibrant有些没有，那你也无法判断出哪个遮蔽信标有Vibrant

你只有在挑战完成后，才能知道所完成的信标的效果。

### /kill的作用

在该模式中，善用/kill会帮助你节省很多事情，具体可以有这些场景：

+ 如果离下一个想去的挑战太远了，而路上恰好会经过营地，在时间充裕且没有接取<mob>Hubris</mob>的情况下，可以考虑使用`/kill`来快速回到营地，节省一半时间
+ 当前时间因为接取绿信标后大于15分钟时，你是无法通过轮次时间奖励正常完成时间条件的任务的。此时你可以使用`/kill`来快速缩减时间，以此来完成任务
+ 接取<mob>Side Hustle</mob>时，如果感觉诅咒太多，打的太吃力，本轮难以按时完成时，可以使用`/kill`来快速跳过这一轮，不会算你整局游戏失败。

### 最后一轮能干什么？

出于结算顺序的问题，轮次结算的顺序在大多数信标之前，因此最后一轮你可能无法正常获取部分信标的效果。

可以正常获取的类型：

+ 红信标与白信标
+ 紫信标与暗灰信标获得的Pulls
+ Chronotrigger获得的Pulls

不能正常获取的类型：

+ Sacrificial Ritual与Gambling Beast的效果
+ 紫信标与暗灰信标获得的Curses
+ Opal Offering的效果
+ 完成任何任务/试炼所获得的直接奖励
+ 任何飞箱的生成
+ Knife Edge获得的Pulls


### 任务完成的时刻

这里需要着重提一嘴，部分任务目标的完成瞬间视作下一轮开始时，例如：

获取Curse的任务/见到信标的任务

这些任务是算在下一轮开始时完成的，因此部分任务无法在下一轮开始时正常获得效果，例如Route Indigo(但信标刷新后可以起效)，并且在信标刷新前，也不会生成灰色信标。


### LR Token

很多人不知道这玩意啊

在指南针→商城→右下角展开→底下的Consumables(炸弹图标)中，你可以使用购买到的LR token，左键一次就是使用一次。

![笔者在截图时不小心用了一个，引以为戒 =400x](/assets/img/lootrun.md-07-02-15-42-05.png)

使用之后，会为你**任何存档下一次结算LR**时，增加一层每日奖励的效果，也就是每层+1rr +10pulls

最多同时使用三次，使用后即刻消耗，效果在下一次结算时生效后消失

在拥有大量Pulls(600+)却缺少rr时，使用lr token是一个不错的选择。

**强烈建议在当局临结算前，再使用token**

LR token的价格如下：

+ 4银牛=6 lr token
+ 8银牛=15 lr token
+ 16银牛=32 lr token

约等于15le换一次rr

值得说的是，商店会随机刷新token折扣，最高6折，此时更加划算。


:::warning
这玩意在使用之后，无法撤销效果。

而且非常容易误触到，非常闹麻。
:::

### 关于Radiant Hunter

Radiant Hunter的目标是要多杀radiant怪，只需要Chance叠到10%以上，即可在每轮生成出充足的Radiant怪。

在选取挑战时，优先选择Defend，其次选择Slay，如果实在不行，也可以选择洞穴，但是**不进去开箱**，而是转头出去找Radiant野怪，这也一样算数，但是得挑战开始后才计数。

在Chance较低(10%左右)时，Destroy很有可能无法刷出充足的Radiant怪。

### 关于Lights Out



Lights Out的目标需要尽可能减少击杀radiant怪。

优先选择怪物少的洞穴，其次选择Defend，再不济选Destroy，而Slay一个都不要碰。

在Chance少的阶段，选择怪物少的洞穴会比较省事，进度加的较少。

而Defend，有个技巧是选择高攻速、有爆炸的武器(对我说的就是Warp)，在挑战开始时，一直平A仇恨在目标点上的怪物，**尽量不要打死任何一只怪物，只靠拉仇恨来通过挑战**。

Defend挑战刷出来的怪物总量实际上有上限，四波左右就会刷满。大约在目标点被打到一半后，所有的怪物仇恨基本都会在你身上了，此时就可以放心绕圈了。

在Chance较高时选择Defend，能让你轻松0进度通过挑战。

但需要注意的是，部分Defend无法使用这一招，例如峡谷的农场DEF、空岛的鸟巢DEF之类的地方。


此方法需要怪物诅咒够多且自身Boon较少，免得平A把怪打死，否则这样更伤。

而如果你的boon足够高，高到打destroy都是秒杀的程度，那也可以选destroy，但需要注意的是Chance高的情况下，destroy很容易直接涨很大一截进度。
