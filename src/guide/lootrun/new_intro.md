## 关于Lootrun

Lootrun，即跑箱，通常来说指玩家用效率最高的方法去在一定场地内搜刮箱子，以此来获得装备去自用或者卖钱

而Lootrun模式是一个整合了这种思想的半肉鸽玩法，玩家需要在一定场地内完成各类挑战，在随机性的影响下完成运营，获取更高的奖励。

通常情况下，lr的终极目标即获取稀有度最高的Mythic品质装备。当然，你也可以选择获取更稀有的Shiny Mythic装备，其与Mythic功能一致，但是增加了独特计数器与附魔光效，更具收藏价值。

>人话：Shiny mythic就是骗氪佬的

### 传统LR方式

这里先介绍一下玩家群体间常说的"传统LR"

你需要穿戴全身LBLQ套，去特定区域内开宝箱

可以使用wynntils的LR路线功能，它能显示其他玩家录制好的路线，这样你就可以增加效率了

一般来说，T1-T4的宝箱一个都不会放过，除非实在是太难去了。

T1-T2宝箱的刷新时间一般在一天，T3-T4会在三天，通常来说三天收一次菜即可

当然，这种传统LR效率偏低，一般仅仅只是为了收菜，也不是本文专注的点，只是为了补全背景。


### Lootrun模式是怎么玩的？

你可以将lootrun模式理解为一种类肉鸽模式。

你的唯一目标，就是尽可能增加你的奖励。

游戏开始后，每轮你都会被分配若干挑战地点，它们由不同颜色的信标指引。

每个信标代表一种特殊效果，有些信标会给予你增益加成，而有些信标会提高你的收益并同时增加难度。

关卡一般以战斗为主，哪怕是搜刮洞穴的关卡也存在大量战斗环节

在完成该信标指引的挑战后，你就可以获得这个信标的效果。

除了搜刮洞穴的挑战，其余挑战在成功完成后，还会获得一个轮次宝箱作为奖励。

每一轮结束时，怪物都会获得属性加成，你需要不断提升自己才能通过更难的挑战。

在所有轮次用完，或者自己主动结算后，你会被传送到挑战起点。

你这局获得的pulls,rr,sac都会添加至最终宝箱中，转换为奖励，等待你的开启。

截止至2.2版本，一共有7处**Lootrun Camp**

它们分别位于**Canyon Of The Lost**、**Molten Heights**(火山)、**Sky Islands**(Sky)、**Corkus**、**Silent Expanse**(se)、**Fruma West**、**Fruma East**

你可以找到**Lootrun Camp**中的<font color=FF55FF>**Lootrun Master**</font>来开始lr

每个地区的LR都会有一定的任务前置和洞穴前置。

任务前置需要完成特定的任务才能解锁，而洞穴前置需要将地区内指定的洞穴全部完成才能解锁。

其中，任务前置为账号通用，只要有一个存档做完任务即可全部解锁；洞穴前置为角色独立，使用新的存档时仍然需要再完成一次洞穴前置。

+ Corkus的Avos洞穴挑战仍然需要你完成`The Envoy Part II`才可入内，这一项没有被列为强制前置，需要注意。

## 一局 Lootrun 如何进行

与Lootrun Master对话后，你就可以开始lootrun了

你可以在此看到挑战的基本信息

![](/assets/img/lootrun8.jpg)

每个账号在每天每个区域第一次完成lootrun时，都能叠加每日奖励，详见文末。

在开始游戏后，你可以看到计分板出现了计时器以及剩余轮次数

![](/assets/img/lootrun9.jpg)

这个模式说白了很简单：你需要在计时器结束前，尽可能多地完成更多的轮次，获得更多的奖励。

每轮挑战的目标基本是战斗，完成后即可获得奖励。

在你觉得撑不下去时，可以主动找Lootrun Master进行提前结算

![](/assets/img/lootrun12.jpg)

结算效果等于直接放弃接下来所有挑战数

若完成的挑战数小于4轮，则不会正常结算，将会判定失败，并且不会获得任何奖励

### 关于离线

游戏进行中时，离线/切换其他存档时，你当前存档的游戏将会暂停

若你已经进入挑战，在上线后你当前的挑战将会重置到刚进入挑战时。

处于洞穴挑战中时，不会重置已经开过的T3/T4箱子，且进度保留。

### 关于NPC

在lr期间，你不能跟除了铁匠、鉴定商、lr大师以外的npc交互

跟铁匠交互可以修理你的自制，跟鉴定商交互可以提前得知你开到的物品。

特别地，你唯一将身上的物品转移至银行的渠道是通过使用RANK的宠物运送功能

~~这真的不是骗氪吗~~

### 关于挑战CD

每个区域在开始后，都会有15分钟的冷却CD

如果你结束的过快，则会受到该CD的影响

各区域的冷却CD独立，且账号通用

也就是说，你可以用任意角色在不同区域同时开始游戏

但是，多个角色不能连续在同个区域开始游戏

### 关于游玩区域限制

每个lootrun地区都有限制一定游玩区域

当你离开这个区域后，会显示`return to playable area in X second`

千万不要以为这是提示，**这是警告**

在倒计时结束后，你就会被**强制结算**并传送回camp

注意当你出现了这个提示并且限时内无法回去时，一定要使用`/kill`来回到camp

这个真的很重要！！！

但是值得一提的是，在sky掉虚空了会把你拉回来，不用担心，只是扣你个90%血罢了。



## 挑战 / Challenge

挑战一共分为5大类
| 名称 | 目标 | 备注 |
| --- | --- | --- |
| Spelunk | 开启洞穴内所有的T3-T4箱子 | 每次进入挑战才会刷新箱子 |
| Slay Mobs | 消灭所有怪物 | - |
| Slay Target | 消灭指定怪物 | 指定目标不一定第一轮就刷新 |
| Destroy | 消灭指定目标 | 类似于拆塔，目标不会攻击没有AI且血量极高 |
| Defend | 保护指定目标 | 只有一些怪物才会攻击目标；每5秒刷新怪物 |

在每次挑战完成或者失败后，怪物都会受到轮次增益，百分比增加血量及攻击(获得绿信标效果时除外)

![](/assets/img/lootrun.md-07-16-02-35-49.png)

这个数值在不同的地区而不同，低等级的地区会有更高的轮次增益来补偿难度

并且，根据你完成的挑战难度，会给予1-3pulls的轮次奖励。

大部分挑战都是1Pulls，少数较难的挑战会给予2Pulls，有且仅有Fruma东部存在若干3Pulls的挑战。

若你在挑战中死亡，或者防守目标被完全破坏，你本次挑战将会被判失败

失败后，你的总轮数上限-1，同时你不会得到该次挑战的信标效果

### 关于信标连续出现限制

有这个机制的信标，意味着这个信标在本轮保持出现状态且完成任意挑战后，下一轮不会继续出现

同理，刷新会导致该信标不会再在本轮重新被刷出来

但是，刷新后该信标消失时，下一轮仍然会继续出现

举个例子：

本轮出现了红、绿信标，且你走进了任意一个信标(不管是不是红绿)，那么下一轮你不会刷出来红绿信标。

本轮出现了红、绿信标，但是你刷新了一次，此时本轮不会再刷出来红、绿信标，但是下一轮你仍然可以刷出来一次红、绿信标。

## 计时器 / Timer

一旦计时器耗尽或者轮次数耗尽，你都会被立刻结算并且传送回Lootrun Camp

获取时间的方式通常为轮次补偿、绿色信标以及部分任务

当挑战开始时，都会获得1min的跑图补偿时间

当挑战成功后，都会获得1.5min的挑战补偿时间

在Fruma地区，你将会获得1.5min/3.5min的补偿时间。

大部分情况下，死亡或挑战失败均会扣除1min的惩罚时间

总时间上限为15分钟，绿信标所获得的时间可以突破该上限，其余途径均无法突破上限。

在计时器超过15分钟时，进出挑战仅会显示获得1s的时间加成(以此来显示是否处于红信标的轮次)

:::tip 
计时器在很多情况下可能会出现暂停计时的情况，例如：

+ 蓝色信标、灰色信标、绯红色信标等出现GUI界面需要玩家选择的时候
+ 刷出飞箱且玩家仍在飞箱范围中
+ 挑战宝箱尚未开启且玩家仍在挑战区域中


:::


## 祝福 / Boons

在吃到蓝信标或者有任务加成的紫信标、暗灰信标后，你会受到祝福(boon)

祝福会给你带来不同属性的提升以帮助你更好完成接下来的挑战

在吃到蓝信标时，你可以从3个选项(副职等级升级后为4个)中选择你想要的祝福

每个祝福由祝福种类、祝福效果和祝福效能组成

祝福种类决定了这个祝福的生效条件以及叠加层数等，以及是否可以继续增长数值

而祝福效果决定了该祝福能够增幅哪条属性，其数值也和祝福种类有关

祝福效能(Potency)决定了其数值倍率，你可以用青信标和Vibrant信标提升祝福的倍率。

## 诅咒 / Curses

在吃到紫信标或暗灰信标后，你会受到随机诅咒(Curses)

诅咒会给怪物带来加成以提高挑战难度，通常情况下没有上限。

当有上限的诅咒种类达到上限时，获得诅咒时不会再随机到该诅咒。

生命与攻击的诅咒与轮次增幅**加算**

诅咒一共会给怪物带来如下祝福：

+ 生命(每次+30%)
+ 攻击(每次+25%)
+ 辉光概率(每次+2.5%，上限100%)
+ 辉光强度(每次+1)
+ 抗性(每次+2.5%，上限70%)

### 辉光 / Radiance

辉光是一种非常特殊的诅咒。

如果你持有辉光概率的诅咒，那么游戏场地内的所有生物在生成时，均会以该概率随机生成为辉光生物。

受到辉光的怪物会显示白色边框的血条，并且外表上看会附加彩虹特效。

辉光怪物会以你的辉光强度诅咒数量获得更高的生命和攻击，受到辉光的怪物会获得2^power个随机诅咒效果(仅包括攻击、生命、抗性)

当辉光强度达到5及更高时，辉光怪物在死亡时将会自爆，造成巨额伤害，伤害与自爆半径随辉光强度增长而提高。

该自爆伤害极高，极大概率秒人，但大部分情况下，只要不接近辉光怪物，保持一定距离，就不会被该自爆伤害影响。

怪物所受到的辉光强度达到10及更高时，不再增长强度，而是会把辉光效果传播给周围未辉光的怪物，你可以理解为等效至概率上。

## 最终结算

当你结算后，你将会被传送至最终宝箱前，你所获得的pulls、rr、sacrifice都会进行结算，并添加至宝箱中，上一轮sac掉的pulls也会在这里被结算。

对于每个区域的最终奖励宝箱，都会有每周刷新的Mythic、Fabled等物品

开启宝箱后，就会获得奖励。

需要注意的是，除了sac所获得的pulls以外，所有pulls、rr等内容均不会保留至下一轮。

**注意最终奖励宝箱的奖励抽取不受任何lb、lq的影响！**

最终奖励分为如下几个种类：

+ Shiny Mythic：特等奖，与普通Mythic的区别就是多了一个独特的计数器以及只有自己才能看到的附魔特效，没了。一个区域奖池只会有一件Shiny Mythic

+ Mythic：一等奖，通常来说，一个奖池会有4-6件Mythic品质的物品，同时还可能刷新Insulator和Simulator(鉴定道具)。稀有度稍次于Shiny Mythic

+ Ward：一等奖(但稍次)，出率比Mythic略高。

+ Liquid Emerald：二等奖，奖池内通常会有1-2种10个以上le的奖品以及2-3种1-4个le的奖品，非赌狗开到大数目le基本可以收手了

+ Lootrun Tome：三等奖，其只有lr能够产出，通常包含一定数值的lb以及各元素伤害、防御等，同样为角色灵魂绑定

+ Fabled Item：三等奖，除了正常开箱能产出的装备以外，还包含部分只有lr最终奖励才能产出的装备，其中有些装备属性非常不错，还有待读者自行研究

+ 杂物：参与奖，没什么好说的，需要注意的是有时候奖池会刷新非常值钱的装备，例如libra或者cumu，这些值得注意一下


### Pulls是什么

你可以理解为抽卡次数。

完成挑战会给予少量pull，pull的主要途径基本是任务和挑战。

有多少pulls，就会在每次开启时，模拟抽多少次卡。

但是，最终宝箱仅会给予抽出来的物品中品质前36的物品，也就是说只会给你保留36个高品质物品，剩下的全部截断。

### rr是什么

你可以理解为重新抽卡。

你可以从任务、试炼、每日奖励和Token中获取rr次数

如果你觉得抽出来的物品不够满意，你可以消耗一次rr次数，重新开启一次宝箱

使用rr次数不会保留你先前抽到的所有奖励，需要谨慎选择，是要以小博大还是见好就收。

### sacrifice是什么

你可以理解为止损。

任务、试炼均可以获得sac次数

sac会放弃当前所有奖励且无法反悔，根据你的sac数来保留当前的一部分pulls至下一局,会在下一局**结算的时候**增加至你的总pulls中。

你的sac越多，能保存的pulls就越多。

sac的保存公式为：

$$(1-\frac{1}{sac+1})×100\%_{\text{(50\%,66.6\%,75\%...)}}$$

:::tip
若下一局failed了，sac所继承的pulls会继续保留，直到成功结算为止

sac所保存的pulls一样可以被下一局的sac一起继承

:::

### 每日奖励

在满级后，每日奖励包含+5pulls以及+1rr，拥有银牛订阅时翻倍

注意：这仅适用于每日第一次**成功结算**的局数

这意味着，如果你今天已经吃了每日奖励，你仍然可以保持已经开始的游戏不结算，并等待至第二天每日奖励刷新时再进行结算，以此来吃到每日奖励

每日奖励的刷新时间是夏令时北京时间中午十二点，冬令时中午十三点    

特别地，如果你每日第一局失败了，不会消耗每日奖励

### 关于奖池刷新

奖池刷新时间为北京时间每周六凌晨，冬令时为3am，夏令时为2am

当奖池刷新时，已经结算并保存待开启的pulls会**直接消失**

但是未结算的局不会自动结算，所以可以留着等奖池刷新再开


## 特殊规则

出于结算顺序的问题，轮次结算的顺序在大多数信标之前，因此最后一轮你可能无法正常获取部分信标的效果。

可以正常获取的类型：

+ 红信标与白信标
+ 紫信标与暗灰信标获得的Pulls
+ Chronotrigger获得的Pulls

不能正常获取的类型：

+ Sacrificial Ritual与Gambling Beast的效果
+ 紫信标与暗灰信标获得的Curses
+ Opal Offering的效果
+ 完成任何任务/试炼所获得的直接奖励
+ 任何飞箱的生成
+ Knife Edge获得的Pulls
