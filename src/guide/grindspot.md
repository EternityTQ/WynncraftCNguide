## 介绍

经验刷怪点，游戏内又名Grind Spot，是一种高效率高风险的获取经验的方法

其不同于任务、地牢，经验刷怪点顾名思义，直接依靠击杀怪物所获得的经验来升级

其经验获取效率往往是其他刷怪点的数倍，同时通过grindspot升级是最有效率的升级方式

同时正常来说，凡是wynntills地图内标有经验点的地方，其怪物均不会有经验以外的任何掉落物，请知悉

:::danger
Grind Spot的怪物强度往往高于其他怪物

通常来说，非常不建议一个人前往Grind spot进行刷怪

在效率极低的同时，还有超高的死亡风险

强烈建议召集队友，或者**使用`/partyfinder`来寻找队伍**

在队伍中确保至少有1-2名奶妈(球法/血萨)以及数名打手的情况下前往Grind Spot进行刷级
:::

在Wynntils Map中，你可以看到非常多的Grind Spot

![](/assets/img/grindspot.jpg)

这些基本都是玩家总结的，非常高效率的刷怪点

本文中，将会对贯穿整个游戏流程的，**常见**的Grind spot进行介绍
>意思就是你基本只能在这几个点找到刷怪的队伍

:::tip 如何提升经验获取效率？

提升经验获取效率的方法有三种，强烈建议全部使用

1.在有Double XP bomb的线路进行刷怪

2.在刷怪时使用Rank的Mob Totem

3.身上全身都穿着具有经验加成的装备

三点全部集齐后，你的经验获取效率将会原地起飞
:::

:::tip 骷髅头是啥意思？
下文中，会有部分刷怪点带有"💀"标识。

它们表示这个刷怪点相对危险，比较推荐跟着队伍来混，单刷可能会被秒。
:::

:::danger 不要挂机！
按照Wynncraft的经验获取方式，你必须至少对怪物造成一定伤害才能获取到经验

同时，你能获取到的经验根据你造成的伤害百分比决定，大约打到15%就能拿满这个怪物的经验了

所以，请不要只在刷怪队伍中挂机，这样你的效率将会无比低下，只能拿到保底的队伍加成经验
:::



## Lv.1~Lv.15 大树下

![](/assets/img/grindspot.md-03-30-02-01-48.png)

<CC>-264 69 -1541</CC>

这个点位上来就可以过来。

怪物都非常呆，非常安全。

中间插一根mob totem后基本无脑刷，非常爽。

## Lv.10~Lv.30 蘑菇平原 

![](/assets/img/grindspot2.jpg)

<CC>621 62 -1544</CC>

这个点位基本可以一个人刷

但是有远程，需要格外小心，可能会被秒。

好处是离城镇近，如果被打残了直接跑路回城镇补给就可以了

20级后比较乏力，但还是可以接着打

## Lv.18~Lv.35 蜘蛛山 💀

![](/assets/img/grindspot3.jpg)

臭名昭著蜘蛛山

**非常不建议一个人单刷**，怪的质量奇高无比，有控制有位移

如果有组队的话，这里是个不错的点


## Lv.20~Lv.45 墓地

![](/assets/img/grindspot4.jpg)

大爹级刷怪点，但是有[前置任务](/quests/lvl11-20/level%2020%20-%20grave%20digger.html)

怪的质量挺高的，有大量远程

但是胜在地点小数量大，可以进去打一圈怪后**马上跑出来**

等怪刷新了一波之后再进去打

## lv.40~lv.55 蜘蛛洞 💀

![](/assets/img/grindspot6.jpg)

这个点位刚下去的地方是一个半安全点。

你可以在里面打完一波怪之后，回到安全点回状态，然后再下去打。

这个蜘蛛洞质量也非常高，足够打到55级

虽然需要漂洋过海才能过来，挺麻烦的:skull:

这里可以直接从Nemract坐船过去。

## lv.50~lv.70 Herb Cave 💀

![](/assets/img/grindspot7.jpg)

这个刷怪点的质量奇高以至于你能一口气刷到70级

虽然其实65级就已经有点乏力了。

但是要注意，这个刷怪点也是非常恐怖的！不建议单刷

队伍建议2~4人即可

不过目前基本上很少会过来这个点刷了，因为过来需要经过一个小BOSS，二周目刷级基本懒得打这个BOSS，于是渐渐就没多少人来刷了。

## Lv.55~Lv.85 肉洞

![](/assets/img/grindspot11.jpg)

其实这里并不是严格意义上的经验刷怪点，因为它有怪物掉落物

但是这个点实在是太绝了，隐藏刷怪点属于是，效率也很不错，甚至是可以打压herb cave的存在

位置在<CC>-949 16 -5515</CC>，从图上的洞穴进去

洞内可以选择站在四周的墙壁上，有很多无敌点，非常惬意。

>而且这个地方有掉落物，运气好的话还可以出把[pure](/guide/advancesystem/mythic.html#pure)，小声

这个洞穴内有一个需要注意的地方是，最里面会刷一只小BOSS，技能是定期拉取周围的玩家，对于穿着经验套的适应等级玩家来说会非常难以处理。你可以站在高处按住**潜行键**来保证自己不被拉取下来，也可以跟着队伍的奶妈保证自己血条健康

## Lv.65~Lv.90 瀑布洞 💀

![](/assets/img/grindspot8.jpg)

臭名昭著瀑布洞

强度也非常非常高，从这个刷怪点开始队伍强度就要大大提高了

其中包含远程怪

推荐3~8人的队伍，但是这个点现在很少有人去了，因为瀑布洞强度过高，肉洞又简单又多经验，属于是基本被上位替代了。

## Lv.85~Lv.105 Frozen Fort

![](/assets/img/grindspot.md-03-30-02-12-22.png)

![](/assets/img/grindspot.md-03-30-02-23-45.png)

非常...小众的刷怪点

在这里你只需要找个高处站着刷就行了。

好处是可以单刷，非常安逸

当然肯定是没隔壁垃圾场快的。


## Lv.80~Lv.105 垃圾场 💀

![](/assets/img/grindspot9.jpg)

你 爹 来 了

降维打击的经验获取效率

这就是**垃圾场**

但同时垃圾场的怪物强度也爆炸高，奶妈质量一定要很高！

包含大量远程弹幕怪，不及时处理的话会给队伍造成重创，需要注意

## Lv.105~Lv.120 教堂 💀

![](/assets/img/grindspot10.jpg)

需要注意的是，教堂的强度非常高，经验套稍有不慎容易被秒。

可以选择在后半场插图腾，如果在前半场插图腾，可能会在教堂外面刷新远程怪秒杀玩家。

可以单刷，但必须要带消耗品。

需要[前置任务](/quests/lvl91-100/level%20100%20-%20a%20journey%20beyond.html)

## Lv.105~Lv.120 蝙蝠洞

位于Fruma森林右下角。

![](/assets/img/grindspot.md-04-29-23-02-59.png)

强度其实还算行，两三个人就能刷

目前是105+大部分人的刷级点

但是飞行怪很多。

测下来法师和萨满组队刷也没问题，刺客和弓手推荐单刷该点位。战士理论上也可以单刷。

只要有点移速就能随便单刷，手法是绕圈跑，怪物打不到你。




## 推荐练级散件

### 观前提醒

本栏目推荐的装备仅供二周目及以后的玩家练级所用，为了追求经验加成，肯定会丢失大量战斗属性。

第一次游玩Wynncraft的萌新切勿参考本页面

本栏目将整个练级过程划分为若干过程，一般你要做的就是：到达下一个阶段→更换这一阶段的装备→开始刷级，重复这个过程即可，非常懒人。

当然，如果你对本栏目的装备非常不满意，这里也非常欢迎你自己找：

首先，打开https://wynnbuilder.github.io//items/

如图所示，右侧红框输入经验加成的条件，左侧勾选你想要的部位，然后就可以搜索你心仪的装备了！

![](/assets/img/grindspot.md-10-24-22-55-13.png)

当然，最好去市场搜索一下价格！




### 推荐消耗品

在刷级的时候，其实消耗品给的经验加成也非常相当可观，甚至能顶一套装备的经验加成，实现加一倍的收益。

如果读者没有制作等级，可以考虑自行购买素材，然后交给群里大手子帮忙代做，一般不会收手续费。

当然，低等级其实也不一定要用消耗品，可以考虑只做药水，到50+之后就可以开始猛灌药了。

另外，善用[Wynnbuilder的自制页面](https://wynnbuilder.github.io//crafter/)，能直接看你做出来了什么东西。

药水：

老生常谈蜘蛛蛋`Lucky Spider Egg`，非常便宜的素材，8级就能用，用这个素材做的药能一路吃到120级。

一般塞6个，如果你觉得次数太少，那就换成1-2个的`Nivlan Honey`

卷轴：

低等级用`Outdated Newspaper`，高等级稳健点用`Stolen Goods`，想要更好的就`Adventurer's Diary`

一样塞6个就好！

食物：

用`Dried Gill`就可以了，一路吃到通关。


### 第一阶段：Lv1~Lv29

这里推荐两类装备

第一类是标准散件，你可以使用附带有经验加成的散件，等级到了就慢慢换上去即可

目标是凑齐更高的经验加成。

这一阶段的装备比较不固定，你可以挑选你自己觉得可以的，一直用到29级即可！

前期的怪都非常好欺负，可以随便选。

| 头盔 | 胸甲 | 护腿 | 鞋子 |
| --- | --- | ---- | ---- |
| Heliophilia(1le) | Guard's Garment(7eb) | Waist Apron(任务获取) | Silken Slippers(3le)|
|   | Blessed Wrappings(15eb) | | Audacity(25eb) |

其中，Waist Apron需要你做完[Infested Plants (level 4)](/quests/lvl1-10/level%204%20-%20infested%20plants.html)后才可使用。

饰品的选择如下：

| 戒指 | 手镯 | 项链 | 
| --- | ---- | ---- |
| Rarity(8le) | Keeper(3le) | Beauty(5le?) |
| First Steps(任务获取) | | Swift(1le↓) |


需要注意的是，rarity非常贵，但是非常好用，**足够你用到120**，真的非常推荐买一个，可以给你之后所有存档用

First Steps需要你做完[Cook Assistant (level 3)](/quests/lvl1-10/level%203%20-%20cook%20assistant.html)，但是只有一个，还想再装的话可以去市场买一个，也算挺便宜。

戒指位的饰品之后很长时间都不会换了！


第二类是笔者重点推荐的装备，笔者在这里更推荐你用`Corrupt Chain`素材做一身装备，每个装备塞6个`Corrupt Chain`，一共需要24个，这个做出来的装备1级就能有极强的杀伤力。

但是`Corrupt Chain`基本没货，得你自己去刷，在Ragni附近找到下图所示的红方块，打死有概率掉落。

![](/assets/img/grindspot.md-03-30-10-45-28.png)

做出来的装备足够你杀到29级。

这一阶段主要在大树下和蘑菇平原刷级

### 第二阶段：Lv29~Lv40+

![](/assets/img/lianji2.jpg)

等到29级后就必须要换上冒险者套了

这是这个等级区间最无脑的选择，冒险者套会提供非常高额的属性加成以及经验加成

非常推荐！简单无脑

这一阶段主要在墓地刷级

尽量刷到40+，如果感觉刷不动了就可以撤退了！

出于懒人的考虑，饰品推荐如下：

戒指：不动

手镯：不动，但可以考虑更换为[The Mercenary (level 30)](/quests/lvl21-30/level%2030%20-%20the%20mercenary.html)任务获得的`Vindicator`

项链：可以考虑更换为DS副本兑换的`Witherhead's Talisman`


### 第三阶段：Lv40+~Lv55+

这个阶段非常随缘，全看你具体几级。

另外，冒险者套觉得吃力了，就马上全部脱下来，不要留单独一两件。

这里按照笔者经验，推荐装备如下，按照你的等级随便选能穿上的即可

| 头盔 | 胸甲 | 护腿 | 靴子 |
| ---- | ---- | ---- | ---- |
| Hero's Mask(lv50) | **Drizzling Doublet(lv56)** | **Bridge of the Divide(lv51)** | Seven-League Boots(lv44)|
| **Venison(lv54)** | Noisemaker(lv51) | Fleet(lv43) | **Galloping Spurs(lv40)**|
| Bloodied Wreath(lv45) | **Ragni's Mail(lv50)** | Moisture(lv51) | Durum's Journey(lv48)|
| **Illuminite(lv55)** |  Gale Burst(lv45) | | |

这里做一点补充说明：

标粗的装备都是非常推荐先看看的。

Hero's Mask头盔非常超模，血量非常多，但是是活动装备，目前已绝版(似乎?)，市场非常昂贵，因此仅作列举，不作推荐，如果有的话可以考虑带这个。

Seven-League Boots靴子非常可以，但是点数需求非常高，容易因为这个穿不上其他的装备，所以需要谨慎考虑。

饰品位基本不修改，只修改一个项链，`Criistal`，要在Ice Barrow副本兑换

当然，如果你买不起`Rarity`的话，这里笔者推荐一个下位替代，`Precious`，加点数加经验，3le左右一个，非常便宜。

这一阶段基本在蜘蛛洞里面刷，刷到吃力了就去下一个阶段。

以上装备基本可以在市场买到，胸甲有一个推荐的是`Matryoshka Shell`，但是这个用钱不能解决问题，必须得去boss祭坛刷，位置在<CC>-698 83 -630</CC>，详细[参考这里](https://wynncraft.fandom.com/wiki/Matryoshka_Shell)

### 第四阶段：Lv55+~Lv75+

这一阶段要替换的不多。

头盔、胸甲基本不变，贯彻懒狗精神

裤子必须换，等级到了之后换成`Greaves of Honor`，58级，需要在[An Iron Heart Part II (level 58)](/quests/lvl51-60/level%2058%20-%20an%20iron%20heart%20part%20ii.html)任务中获取，有要求，详见任务页面。

鞋子必须换，60级后换成`Bad Wolf`，非常贵，但效果非常好。

手镯可以换，`Vanguard`，在CIP副本获取，77级。

这一阶段主要在肉洞刷级，因为强度不高，所以装备基本可以不用换。

刷到75-80级就可以准备走了，最好77级以上再走！

### 第五阶段：Lv75+~Lv105

这一阶段全身都要换一遍！

![](/assets/img/lianji6.jpg)

如上图所示

只要等级到了，一件一件替换就可以了

注意**头盔非常贵**，可以使用下位替代<font color=EC4791>**Speaker**</font>，这个很便宜

胸甲可以在市场买到

裤子来源是[The Qira Hive (level 80 - 100)](/quests/lvl71-80/level%2080%20-%20the%20qira%20hive.html)，打完水层就可以下去换了，非常快，其余均可以在市场购买到


当然，如果你够闲，笔者非常强烈推荐你去做一遍[??? (level 80)](/quests/lvl71-80/level%2080%20-%20z？？？.html)，获得的套装是全游经验加成最高的。

仅在找不到车队还单刷不了的情况下再尝试这个，因为这套经验套装在你其他存档想用的时候也得再做一遍任务，非常麻烦。

这个阶段基本在垃圾场刷，要待很久！




### 第六阶段：Lv105~Lv120

这一阶段裤子保留，其他参考下图

![](/assets/img/grindspot.md-06-10-19-50-08.png)

头盔可以在市场买，胸甲是在Fort Torann的盔甲商店买的

`Diaspora`的点数需求极高，如果武器无法使用的话，可以考虑将鞋子换成自制，配方为6个`Lucky Rabbit's Foot`，roll到40xp以上就可以了，非常便宜。

手镯看情况换，戒指其实也可以不用换，只要你够懒。

这一阶段主要在蝙蝠洞刷。
