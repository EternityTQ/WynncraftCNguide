世界事件（World Event）是在 2.1 版本加入游戏的一种日常战斗机制，你可以简单理解为一个会在世界各地定时出现的“小型副本”。

世界事件开始前会有一段准备时间。玩家可以前往事件地点等待，倒计时结束后进入战斗，依次消灭数波敌人并击败最终 BOSS，即可完成事件并获得奖励。

世界事件会给予经验、装备、素材等各种奖励，部分事件还拥有只能通过该事件获得的专属装备与制造原料。

对于中后期玩家来说，重复刷世界事件的主要目的通常是获取这些奖励并赚钱。

## 如何参与世界事件

在游戏的任务书中，你可以查看当前即将开启的世界事件。

![](/assets/img/we1.png)

世界事件开启前一段时间，你可以在任务书中看到对应事件，并对其进行追踪。

尚未进入准备阶段的世界事件不会显示为可追踪状态。

追踪事件后，前往对应地点即可看到当前的倒计时。

![](/assets/img/we2.png)

你可以趁这段时间与周围玩家组队，也可以提前与朋友组好队伍再前往事件地点。

倒计时结束后，在场的玩家会正式进入事件。

每支队伍都会进入各自独立的事件实例，不同队伍之间的战斗进度并不共享。

如果你没有加入任何队伍，则会以单人队伍的形式开始事件。

:::tip

普通世界事件并不要求提前组织完整队伍。

如果只是路过看到附近有事件开启，通常也可以直接前往参加。

通常来说，一般是会在任务书上翻阅哪个世界事件即将开启，然后就赶路前往地点。

在Fruma版本更新后，pf能找到"we队"，也就是专刷we的队伍，你可以加入他们，一起组队刷we。

:::

## 刷新机制

世界事件并不是所有事件共享同一个刷新计时，而是按照所在地区被划分为不同的**刷新池**。

例如，某几个位于同一区域的世界事件会共用一个刷新池。同一时间，一个刷新池中只会存在一个正在准备或进行中的世界事件。

当这个地区没有世界事件存在时，游戏会以每分钟为单位判定新的世界事件是否刷新。

不同地区的刷新速度并不相同，因此有些地区的世界事件非常频繁，而有些高等级地区则可能需要等待更长时间。

换句话说，如果你只是为了刷世界事件赚钱，并不一定需要一直蹲在同一个事件地点。观察多个地区当前的世界事件并在不同事件之间移动，通常会更加有效率。



### 世界事件炸弹

使用 **World Event Bomb** 后，可以让当前服务器中的普通世界事件全部进入激活状态并开始倒计时。

特殊的大型世界事件不会受到 World Event Bomb 的影响。

## 战斗

世界事件开始后，每支队伍都会进入自己的战斗房间，同世界事件的各队伍之间的进度不受影响。

普通世界事件通常由数个波次组成。每一波都会生成一定数量的目标怪物，清除当前目标后即可继续推进事件，最终击败 BOSS 即可完成世界事件。

:::warning 等级修正

世界事件中的敌人会根据队伍中**等级最高的玩家**进行等级与属性修正。

因此不要指望单纯依靠高等级进入低等级世界事件来实现等级碾压。

反过来说，如果你和等级明显高于自己的玩家组队，也需要注意敌人的强度会以队伍中的最高等级玩家为基准。

:::

不同世界事件的长度并不完全相同。

较短的事件可能只有少量波次，而较长的世界事件则可能持续数分钟，并拥有更多波次和更复杂的敌人组合。

事件过程中，如果队伍中仍然至少有一名玩家存活，队伍仍然可以继续完成世界事件。

如果队伍中的所有玩家全部死亡，则本次挑战失败，并且无法在该次事件中重新复活继续战斗。

失败后只能等待该事件下一次开启，或者寻找其他正在准备的世界事件。

## 奖励

完成世界事件后会获得对应事件的奖励。

不同世界事件提供的奖励有所区别，常见奖励包括：

- 经验值
- 普通装备与其他随机物品
- Dungeon Keys
- Runes
- 制造原料
- 世界事件专属装备

其中部分装备和制造原料只能通过特定世界事件获得。

因此即使已经进入游戏后期，世界事件依然具有一定的重复刷取价值。


## 如何刷世界事件

如果只是升级途中遇到世界事件，可以把它当作一个顺路参加的小型战斗内容。

而如果你的目标是专门刷世界事件赚钱，则更重要的是关注当前服务器不同地区正在准备的事件，而不是长期等待某一个固定地点刷新。

由于不同地区拥有彼此独立的刷新池，同时观察多个区域通常可以减少等待时间。



## 大型世界事件

除了普通世界事件之外，游戏中还存在更加少见、难度也明显更高的 **Major World Event**。

这类事件无论是队伍配置、战前准备还是战斗机制，都与普通世界事件有明显区别，因此不在本页面展开。
