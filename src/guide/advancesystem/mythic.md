## 总体介绍

### 什么是神话物品？

神话物品是最高级的物品品质，其拥有非常强力的属性面板，以及最难获取的稀有度。

在Wynncraft中，一个常见的终局目标往往是获取更多的神话物品。

神话物品拥有紫色的品质和物品名，其盒子是深紫色，非常好认。

### 我要如何获得神话物品？

通常来说，神话物品有如下几种获取渠道：

+ 怪物掉落：非常罕见，但是往往是新手第一把神话的获取方式。在对应的等级区间，怪物有百万分之七的概率掉落神话物品，其概率会随着你拥有的loot bonus增加！当然也不会加到哪里去...
+ The Forgery：曾经是神话的较为高效的获取渠道，如今已经化区了。你需要跑一遍所有的腐化副本来抽一次奖，有概率抽到神话。放在今天的获取效率非常低下，已经完全不推荐了。
+ Lootrun：目前最高效的获取渠道，能帮助你获得大量的神话物品。
+ World Event：也能获取神话，只是概率很低。其中有五把黑神话都是只有Annihilation才能产出。

### 神话物品有多少件？



当前版本下，每个职业共有11把神话武器

其中，分为1把低级神话武器(60-80级)，5把各属性的神话武器，1把彩虹神话武器，4把高等级神话武器(100+)

而鞋子为双元素分类，每种双元素组合都有一个对应的神话鞋子，一共10种神话鞋子。

>五职业共十把高等级神话也对应十种双元素组合。（Hanafubuki按照点数要求，归为水气）

需要注意的是鞋子没有低级神话


### Shiny Mythic

Shiny Mythic是比普通神话物品还要高级的神话。

但是！没有什么太大的变化。Shiny仅仅会给神话附加一层附魔光效，以及一个独特的计数器。

计数器有很多种类，但大体上都是记录你拿这把shiny打了多长时间。

纯收藏价值，没有战力上的提升。

### Ascend Mythic

在2.2更新后，Fruma前的神话有了晋升的机会。

晋升后的神话相比晋升前，会提升使用等级限制、提升词条范围、获得新的词条，甚至获得新的Major ID

通常来说，晋升所带来的提升大约是10%\~15%左右。

为了晋升，你需要凑齐以下材料：

七种不同颜色的Ward，它们分别来自：

绿Ward:LR限定Ward

橙Ward:LR限定Ward

粉Ward:LR限定Ward，在Fruma东部池子必刷

红Ward:Raid限定Ward

蓝Ward:Raid限定Ward

黄Ward:Raid限定Ward

紫Ward:Raid限定Ward

同时，你还需要一把对应神话作为燃料来确保你的晋升概率为100%，如果不添加燃料则晋升概率只有30%，非常扯淡。

Shiny神话的燃料可以是普通版本的。

当准备好晋升了，找到城镇里面的Upgrader即可，记得别放错想要晋升的主武器了
