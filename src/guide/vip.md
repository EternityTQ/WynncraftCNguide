对于Rank来说，有几点特殊功能值得介绍一下

### Mob Totem
这里指的并不是萨满的图腾，而是一种持续性增益道具

你可以在游戏内输入/totem来查看和使用你当前所持的图腾

图腾在被使用后，将会放置在地上，拥有明显的模型

![](/assets/img/vip.md-03-04-22-56-01.png)

在使用后，每个图腾有5分钟的持续时间，作用半径为20格

在图腾有效范围内，红名怪物的刷新速度和刷新数量将会大幅度增加

如果配合`Double XP Bomb`或者`Loot Bomb`，效率将会大幅度提高！





**请注意，在城镇内使用图腾是违规的**

当前图腾的主要来源为Rank的每日奖励

在持有Silverbull订阅状态时，每日图腾的数量将会翻倍

:::tip
当天没有使用完的图腾，不会留到明天，每日奖励的图腾只会将你的图腾数量补充至上限。

当然，如果有溢出数量的图腾，那么其数量还是能保留的，举个例子就是银牛订阅刚好过期，或者从拉新奖励中获得的图腾
:::

### 皮肤职业

在解锁了皮肤职业后，你可以在创建职业时选择皮肤职业

皮肤职业对于原生职业来说，仅有特效和名字的区别

在购买了HERO及以上的Rank后，你可以将现有的职业进行原皮肤-特效皮肤之间的切换

![](/assets/img/vip.md-03-05-15-19-43.png)

### 每日饰品箱

在购买了VIP+及以上的Rank后，你就可以获得每日饰品箱

其为最基础的饰品箱，在节日期间也不会转化为节日饰品箱

在持有Silverbull订阅状态时，每日将会额外获得一个饰品箱

:::warning
当天没有开启的每日饰品箱不会保留到隔天！
:::

### 炸弹钟

非常实用的功能

在购买Champion后，该功能默认开启

当其他线路有玩家投掷了持续性炸弹(即：除了Item Bomb、Scroll Bomb、Ingredient Bomb、Party Bomb以外的炸弹)时，

你在当前线路将会收到通知，可以说大部分人买Champion就是为了这个

![](/assets/img/bombbell.jpg)

## SliverBull & Share

在中国玩家群体中，通常称为"银牛"

官网出售价格约为1.1刀一张

银牛是游戏中唯一一个可用现实货币购买的**可交易**道具

其可以用来激活银牛订阅服务，游戏内6张可交易银牛可激活**14天**的订阅服务

银牛订阅主要效果如下：
+ 市场购买税从5%降低至2%
+ 加倍获取ranks的每日道具奖励(图腾、饰品箱)
+ 隐藏盔甲的权限
+ 合成饰品时只需要三合一而非五合一
+ 活动期间的免费活动饰品箱可以双倍获取
+ Raid和Lootrun的每日奖励加倍
  
在官网订阅价格是12刀**一个月**，120刀一年

在部分促销活动中，游戏内使用银牛激活订阅服务将会额外赠送3天时长，或者有10%的折扣

:::tip
游戏内，可以重复进行订阅，其将会延续增加剩余订阅时长

每当你连续保持银牛订阅状态达到31天，你将会获赠5张不可交易的银牛

其不可以挂在交易市场上出售也不可以激活订阅服务，但仍可以在银牛商城购买游戏道具

也就是说大约需要两次半的订阅才能获取一次。
:::

:::tip 在交易市场上出售/购买银牛
银牛并不会以物品的形式存放在你的物品栏中

在出售界面，你可以通过点击右下角的纸条来出售银牛

![](/assets/img/vip.md-03-05-15-23-19.png)

其他操作与出售物品类似。

同理，你可以通过搜索"Share"来购买银牛

![](/assets/img/vip.md-03-05-15-24-03.png)

默认会直接购买最低价，并且会返还多余的绿宝石。
:::



### Silverbull Shop
在游戏中，你可以在Silverbull Shop内使用银牛来购买Bomb、Crates等氪金道具

其购买价格约等于线上商店内购买的价格，但是时常会有特定种类的商品的折扣

你可以经常关注城镇内特有的广告牌，来关注你需要的折扣

![](/assets/img/vip.md-03-05-15-24-23.png)

特别地，你也可以通过指南针来开启游戏内商店

:::details 开启方法
![](/assets/img/vip.md-03-05-15-25-26.png)
:::

在游戏内商店，1张银牛的购买力与1美元相当。

![](/assets/img/vip.md-03-05-15-26-26.png)

你可以在里面自由购买你所需要的商品，**包括Rank**。

同时，还有一种仅在游戏内商店才能购买的道具`Token`，下文会有所提及。

## Crates
饰品箱

购买后可以在游戏内开启，跟抽卡一样

你可以通过在游戏内输入`/crate`来查看你当前持有的饰品箱

饰品同样具有品质：Common / Rare / Epic / Godly / Black Market

饰品箱可以开出玩家特效 / 武器皮肤 / 攻击特效 / 宠物 / 马匹皮肤 / 头饰 等等

同时饰品箱还存在等级

+ T1和T2饰品箱至多开出Godly，至低开出Common
+ T3和T4饰品箱至多开出Black Market，至低开出Rare

T3、T4饰品箱的来源只有在商城购买

注意，饰品有可能重复

:::tip 领取免费饰品箱
游戏内商店的Crate界面时不时会有免费的饰品箱

![](/assets/img/vip.md-03-05-15-28-48.png)

这个领取冷却相当随缘，可以多加关注

:::

### 装扮饰品

在游戏内商店，你可以打开衣柜

![](/assets/img/vip.md-03-05-15-30-34.png)

在衣柜中，你可以预览当前的饰品和改色

![=400x](/assets/img/vip.md-03-05-15-31-03.png)

左键单击即可进入装扮页面。

![](/assets/img/vip.md-03-05-15-34-01.png)

对于头盔、武器部位，你可以自由选择不同的饰品装扮

对于胸甲、护腿和靴子，你仅可选择正常的盔甲装扮。~~什么时候可以伪装Morph~~

对于这些部位，还可以选择Glint改色效果。

Glint可以让你的饰品部位适用不同的着色器，获得更加炫酷的效果。

Glint改色功能只有银牛订阅用户才可使用。

另外，衣柜右侧还有玩家特效、伪装、坐骑皮肤三种功能。

玩家特效一般是围绕在玩家附近的粒子效果

伪装可以将你自己变为各种奇怪的模型，但你自己看不见

坐骑皮肤顾名思义，可以给你的马换成不同种类的皮肤。


### 合成饰品

你可以在游戏内对不需要的、重复的饰品进行合成

五个同等级的饰品可以合成为一个高一级的饰品

对于最高等级的Black Market饰品，合成将会得到10个Epic饰品

在持有Silverbull订阅状态时，合成饰品仅需要三合一

在任意饰品页面中，通过下方入口进入Scrap页面。

![](/assets/img/vip.md-03-05-15-29-50.png)

### 节日Crates
在活动期间，商城将会出售节日Crates

节日Crates中仅会包含非常特别的限时饰品，且**没有Common品质！**

注意不同的节日饰品和常驻饰品之间不能混搭合成

:::tip
每个节日开始时，你都可以在线上商城领取3个免费的节日Crates!

节日期间完成每日任务（使用其他职业完成多次每日任务无效）或公会任务可以获得一个（有银牛订阅的玩家会获得两个）免费的节日Crates。
:::

## Pets
宠物有两种获取途径

比较常见的是在Crates中开出

同时，宠物还可以在线上商店和Silverbull Shop中直接购买，但是稍贵

直接购买的宠物无法从Crates开出

:::tip
不同宠物仅有品质、模型的区别，其他没有任何区别！
:::

宠物可以通过击杀和玩家等级相近的怪物来获取经验，等级上限依Rank等级来决定。

同时，宠物还可以和玩家并肩作战(尽管伤害感人)

:::tip
满级的宠物造成的伤害在新档前期非常有用。

如果你是刺客并且你的技能树包含weightless，宠物造成的伤害会触发weightless的效果。
:::

宠物在20级前将会逐渐提升伤害

在购买Champion后，你可以将宠物提升至最多100级

**但是，20级后宠物只会获得额外的辅助性功能，不会增加任何攻击力**

辅助性功能分别为：派送宠物运送东西、售卖东西

每个玩家最多只能同时召唤1只宠物，在购买Hero后，可以同时召唤3只

:::tip 领取你的免费宠物！
![](/assets/img/pets.jpg)

在官网上的PETS一栏中，你可以在这里领取一只免费的宠物鸡
:::

## Token

一种非常...烧钱的东西

Token的作用相当于一种实现特定功能的道具，一次性使用。

分为如下种类：

### Tracker Reroll Token

![](/assets/img/vip.md-03-05-15-39-25.png)

每个Shiny神话都具有计数器。

这个Token的作用就是将这个计数器刷新为另一种。

注意，刷新后的计数器会在后面附带数字小标，而且每把Shiny神话最多刷新3次。

### Tracker Reset Token

![](/assets/img/vip.md-03-05-15-40-23.png)

这个是用来将Shiny计数器重置到0的，非常诡异。

除了Death计数器以外我想不到有什么场合要用到这个。

### Guild Rename Token

![](/assets/img/vip.md-03-05-15-41-10.png)

顾名思义，用来给你的公会改名。

仅有会长能使用

### Guild Boost Token

![](/assets/img/vip.md-03-05-15-41-38.png)

用来给你的公会提供一系列增益

但是...你订阅银牛就会有这个功能

所以没啥用

### Raid Daily Bonus Refresh

![](/assets/img/vip.md-03-05-15-42-23.png)

你每天第一把Raid就会有每日奖励，如下图：
![](/assets/img/vip.md-03-05-15-42-46.png)

这个Token的作用就是让下一把Raid也能有每日奖励，也就是额外的Pull、Aspect和Reroll次数。

重复使用后会叠加每日奖励的倍数

### Lootrun Daily Bonus Refresh

![](/assets/img/vip.md-03-05-15-43-55.png)

和Raid Token类似，用来刷新lr的每日奖励。

重复使用后会叠加每日奖励的倍数

比raid的稍微有用一点，如果你攒了一大堆pulls又想冲Shiny，就可以用这个。



## Bombs
炸弹

这可不是什么伤害道具，而是一种全服增益

Bombs一般可以为当前线路带来10分钟或20分钟的增益并延迟服务器重启倒计时

也可以是一次性给当前线路的玩家发放道具

同种炸弹不能在持续期间内再次丢掷


### Combat XP Bombs(dxp)

为当前线路带来20分钟的双倍的战斗经验

副本的经验也受加成

与服务器的所有经验加成活动加算，包括dxp weekend、绑定dc给的一天双倍经验。

![](/assets/img/vip.md-03-05-15-55-16.png)
  
### Profession XP Bombs(pxp)

为当前线路带来20分钟的双倍的副职经验，包括采集和制作

![](/assets/img/vip.md-03-05-15-55-24.png)

### Profession Speed Bombs(psp/psb)

为当前线路带来10分钟的双倍的副职采集速度以及制作原料减半（向下取整，但是最小值是1）

![](/assets/img/vip.md-03-05-15-55-44.png)

### Shout Bombs

可以向全服(跨线路)发送一条消息

请注意不要发送敏感信息，会有查水表风险

![](/assets/img/vip.md-03-05-15-55-50.png)

### Loot Bombs

为当前线路带来20分钟的怪物双倍掉落

注意，Loot Bombs的实际效果是掉一个变两个，而不是掉落几率加倍

![](/assets/img/vip.md-03-05-15-56-10.png)

### Item Bombs

为当前线路的每一个玩家赠送1个T4战利品箱子。

能开出神话。

![](/assets/img/vip.md-03-05-15-56-03.png)

### Dungeon Bombs(db)

为当前线路开启10分钟的地牢副本免钥匙资格

不能抵消raid的门票

![](/assets/img/vip.md-03-05-15-56-15.png)

### Scroll Charge Bombs

由原先的灵魂点炸弹转换而来

可以给当前线路的所有玩家填充满卷轴的充能

![](/assets/img/vip.md-03-05-15-56-20.png)

### Ingredient Bombs

为当前线路的每一个玩家赠送一个素材箱子

原料和素材的等级基于玩家的副职等级

![](/assets/img/vip.md-03-05-15-56-24.png)

### Loot Chest Bombs

可以大幅度提升当前线路的箱子质量

LR时飞箱流配合这个bomb效果极佳！

![](/assets/img/vip.md-03-05-15-59-49.png)

### World Event Bomb

可以强制开启当前线路中，出了Major World Event以外的所有World event

就...似乎也没什么用

![](/assets/img/vip.md-03-05-16-00-16.png)

### Party Bombs

开趴，绝大部分情况下没有任何意义，只会造成服务器卡顿（特殊情况下这个卡顿可以对玩家带来正面收益，但不建议使用）

![](/assets/img/vip.md-03-05-16-00-30.png)


## 额外优惠

在商店支付任意订单，约24小时后，你将会额外收到一封邮件，内含一天期限的九五折优惠码，可与促销折扣叠加

如果你想要大额氪金，比如购买CHAMPION，不妨先支付任意小订单，得到优惠券后再来支付大额订单

需要注意的是，==该优惠券绑定账号==，无法借与他人使用

另外，在支付界面的主播码，你可以填入`OLINUS`，也可以额外享受5%折扣。
