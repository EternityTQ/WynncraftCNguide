首先，先介绍一下Wynncraft服务器

Wynncraft是一个运营了十余年的老牌MMORPG服务器，其最大的特色就是能够在Minecraft这一游戏的范围下，不借助MOD，让玩家可以在原版游戏下体验到非常酷炫的RPG系统

其游戏版本为1.20.5+

何谓MMORPG？
>~~Many Man Online Role Play as Girl~~

MMORPG即大型多人在线角色扮演游戏

不过你也可以简单理解为打打打杀杀杀。

当然，这么大型的服务器，如果你能做一些进入前的准备是最好的，能大幅提升你的游玩体验。

以下应该是新手玩家入坑时会问的常见问题：

## 服务器IP是什么？

服务器的IP地址为<copy>play.wynncraft.com</copy> (你可以直接点击复制)

当然，作为一个全球服，你也可以使用以下IP：

+ <copy>as.wynncraft.com</copy> (亚洲服务器)
+ <copy>na.wynncraft.com</copy> (北美服务器)
+ <copy>eu.wynncraft.com</copy> (欧洲服务器)
+ <copy>lobby.wynncraft.com</copy> (进入大厅，而非直接进入游戏)

不同的IP仅有自动连接的线路之差，进入服务器后你仍然可以自由切换线路，而不用重新选择不同的IP！

## 服务器版本是什么？

目前服务器需要`1.20.5+`的Minecraft Java版本

版本统一推荐使用**`1.21.11`**（Fabric），原因下面会说

## 客户端在哪里下载？/ 需要什么模组吗？

启动器推荐使用 **`PCL2`** 或 **`HMCL`** 启动器来下载并管理游戏。

模组方面，**仅需安装 `Wynntils` 这一个 MOD 即可，同时下载必要的 `Fabric API`**：

### Wynntils & Fabric API

`Wynntils` 能大幅改善你的游玩体验，增加小地图、鉴定度显示、个性化GUI等实用功能；运行它还需要同时下载前置模组 **`Fabric API`**。

[Wynntils 下载地址](https://modrinth.com/mod/wynntils/)

[Fabric API 下载地址](https://modrinth.com/mod/fabric-api)

==请注意，Wynntils最新版本需要 `1.21.11` 的Minecraft版本==


## 需要加速器吗？

**需要**

大陆范围内尝试裸连游玩一般会出现非常严重的丢包现象。

这里比较推荐以下两款加速器：

+ **AK加速器**：亚服，加速香港，日常使用
+ **VK加速器**：欧服 / 美服，加速对应区服，在对应服务器可用

请注意，使用时推荐选择两种节点：

1. 中国香港

香港节点在AS服(亚服)游玩可以享受到极低的延迟(两位数)，适合日常用 AK 加速器在亚服游玩。

但是，如果你在组队时被传送到了NA服或者EU服，则需要改用 VK 加速器加速对应区服，否则香港节点延迟会比较高。

2. 日本

日本节点基本上在所有线路游玩都能保持100+的延迟，不高不低，适合偶尔需要跨线路跑动的场景；但亚服日常体验仍以香港节点更优。

## 服务器有汉化吗？

服务器没有官方汉化。

如需使用汉化，可以参考B站汉化视频：<https://www.bilibili.com/video/BV1B99QB1EbM/?>

另外，**`Wynnchayan` 汉化模组可以使用，但必须开启中英对照**，因为玩家社区通常还是采用英文来沟通交流。

也可以使用Wynntils的机翻功能，不过纯机翻容易曲解原意；另一个选择是去英文wiki页面配合网页翻译查看，效果稍好。

## 服务器支持RMT吗？

==绝对不要RMT==

RMT严重违反服务器规定，同时可能会导致你被连锁ban。

## 任务卡关了怎么办？

网页上方点进任务攻略，解君愁。

## 材质包在哪里整？

进服务器就会自动下载，如果你勾选了的话。

如果出现材质包下载失败，可以尝试裸连进服务器，等下载完成后再退出来开加速器
